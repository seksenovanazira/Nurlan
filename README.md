# Аналитика повреждений — ЛТЦ Биржан сал

Локальный сайт для одного пользователя: журнал повреждений, аналитика причин и повторов, профилактика, отчёты. Интернет и установка библиотек не нужны. Учебные записи вымышленные.

## Запуск

Самый простой способ: откройте `index.html` двойным щелчком в Microsoft Edge или Google Chrome. Все три файла (`index.html`, `styles.css`, `app.js`) должны оставаться в одной папке.

Для постоянной работы рекомендуется один и тот же браузер и стабильный локальный адрес:

1. Откройте терминал в папке проекта.
2. Выполните `node server.cjs` (нужен Node.js; на компьютере создания проекта он доступен).
3. Откройте http://127.0.0.1:8765 в браузере.
4. Не закрывайте терминал во время работы. Для остановки нажмите Ctrl+C.

Если команда `node` не найдена, используйте простой способ с `index.html`. Не запускайте второй сервер на том же порту, если первый уже работает.

Хранилища у прямого открытия файла и адреса http://127.0.0.1:8765 разные. В другом браузере также будет отдельный журнал. Переносите данные между ними через резервный JSON. При открытии файла некоторые браузеры ограничивают сохранение; если появится сообщение об ошибке хранилища, используйте локальный сервер. Не перемещайте папку без резервной копии при работе через файл.

## Начало работы

При первом запуске выберите «Загрузить учебный пример» (40 записей и 4 профилактические работы) или «Начать с пустого журнала».

В настройках замените условные населённые пункты и бригады своими значениями. Каждое значение справочника пишите на отдельной строке. Перед вводом рабочих данных очистите учебные через настройки: демонстрационный признак относится ко всему журналу.

Нажмите «Добавить повреждение», заполните обязательные поля со звёздочкой и сохраните. Код объекта необязателен для регистрации, но необходим для автоматического поиска повторов. Используйте постоянный код одного объекта. Плановый срок задаётся пользователем: нормативы компании в сайт не заложены.

Для завершения откройте запись через журнал, нажмите «Изменить», выберите «Устранено» и укажите время восстановления. Нельзя сохранить восстановление раньше регистрации, в будущем или без статуса «Устранено». Введённое содержимое остаётся в форме при ошибке.

## Аналитика

Фильтры периода, населённого пункта, услуги, причины и исполнителя общие для аналитических разделов и отчёта. Статус выбирается в журнале и остаётся активным при переходах; его значение указано под фильтрами. «Сбросить» очищает ограничения и возвращает текущий месяц.

Период применяется к дате регистрации. Открытые и просроченные показатели описывают записи, зарегистрированные в этом периоде, а не все открытые повреждения сети. Для полной картины выберите «Вся история».

Время восстановления равно разнице восстановления и регистрации. Среднее рассчитывается только по устранённым. При отсутствии таких записей выводится «Нет данных». Открытое повреждение без планового срока не считается просроченным. Для закрытого отдельно отмечается нарушение срока.

В сравнении используется предыдущий календарный интервал той же продолжительности и те же фильтры. Разница долей выражается в процентных пунктах. Причины и выводы формируются только из записей журнала.

## Повторность

Новая запись считается повторной, если на объекте с тем же кодом и по той же услуге есть более ранняя запись, устранённая до регистрации новой, а с восстановления прошло не более установленного срока (по умолчанию 30 суток включительно).

Учитывается вся история, в том числе до отчётного периода. Регистр букв и пробелы по краям кода не влияют на сопоставление. Без кода повторность не определяется. Каждая новая запись считается один раз, даже если подходит несколько предыдущих. Доля повторов — число повторных записей / все записи выбранного периода. Это пользовательское правило аналитики, не официальный норматив компании.

В настройках доступны 7, 14, 30, 60 и 90 дней. При изменении срока, редактировании или удалении записей аналитика пересчитывается.

## Профилактика

Создайте работу вручную или кнопкой «Запланировать профилактику» у проблемного объекта. Введите основание, работы, ответственного и дату. История связывается по коду объекта. Просроченные незавершённые задачи показаны отдельно. При завершении укажите дату выполнения и результат.

## Отчёт и Excel

В разделе «Отчёты» выберите период и фильтры, затем «Распечатать / сохранить в PDF». В окне браузера выберите принтер или «Сохранить как PDF», бумагу A4. Для чистого отчёта отключите стандартные колонтитулы браузера. Меню и кнопки скрываются автоматически.

Профилактика включается в отчёт по плановой дате, по всем объектам и исполнителям; это отдельно подписано в отчёте. Повреждения учитывают общие фильтры.

Кнопка CSV выгружает отфильтрованный журнал. В разделе журнала дополнительно учитывается строка поиска, выгружаются все найденные страницы. Формат: UTF-8 с BOM, разделитель — точка с запятой. Если Excel не разделил столбцы автоматически, используйте «Данные → Из текста/CSV» и укажите эти параметры.

## Резервная копия

«Настройки → Скачать JSON» сохраняет весь журнал, профилактику и настройки. Это полноценная резервная копия; CSV её не заменяет. Сохраняйте JSON регулярно и перед очисткой или загрузкой учебного примера.

«Восстановить из JSON» сначала проверяет структуру и значения, затем просит подтвердить замену. Повреждённый файл не меняет существующие данные. Допустимый размер — до 10 МБ.

Хранилище localStorage ограничено браузером. Если запись не удалась, сайт сообщает об этом и не выдаёт её за сохранённую. В приватном режиме данные могут исчезнуть после закрытия окна. При ошибке чтения исходная копия не перезаписывается; в настройках можно скачать исходные данные для восстановления.

## Файлы и проверки

- `index.html` — структура страницы.
- `styles.css` — оформление, адаптация для планшета и печати.
- `app.js` — формы, хранение и расчёты.
- `server.cjs` — необязательный сервер, доступный только на этом компьютере.
- `check.cjs` — проверка расчётов и форматов: `node check.cjs`.

Сайт не синхронизируется с системами компании, не поддерживает общий доступ и не отправляет данные в интернет. Для работы команды понадобится отдельная версия с серверным хранилищем и управлением доступом.
